강의 노트 앱 - 처음 시작하기
============================

이 앱은 강의를 녹음하면 자동으로 텍스트로 바꾸고(음성 인식), 핵심 내용을
요약해주는 프로그램입니다.


1. Claude API 키 발급받기 (최초 1회, 필수)
--------------------------------------------
요약 기능은 Anthropic Claude API를 사용합니다. 본인 명의로 키를 발급받아야
동작합니다.

  1) https://console.anthropic.com 접속 → 회원가입 또는 로그인
  2) 왼쪽 메뉴 "API Keys" → "Create Key"
  3) 생성된 키(sk-ant-로 시작하는 긴 문자열)를 복사해두기

※ 사용한 만큼 비용이 청구되는 방식입니다. 요금 정책은 콘솔에서 확인하세요.
※ 이 키는 본인 것만 쓰세요 — 다른 사람 키를 쓰면 그 사람에게 비용이 청구됩니다.


2. API 키를 앱에 등록하기
--------------------------------------------
  1) LectureNotes.exe를 한 번 실행했다가 그냥 종료합니다.
     (데이터 저장 폴더가 이때 자동으로 만들어집니다)

  2) 키보드에서 Win 키 + R 을 누르고 아래를 입력한 뒤 Enter:

         %LOCALAPPDATA%\LectureNotes

     탐색기가 해당 폴더로 바로 열립니다.

  3) 이 폴더 안에 메모장으로 새 파일을 만듭니다.
     - 메모장(Notepad)을 새로 열고 아래 한 줄을 입력하세요.
       (여기에 실제 복사해둔 키를 붙여넣으세요)

         ANTHROPIC_API_KEY=여기에_복사한_키_붙여넣기

     - 메모장에서 "파일 > 다른 이름으로 저장" 클릭
     - 저장 위치: 방금 연 %LOCALAPPDATA%\LectureNotes 폴더
     - 파일 이름 칸에 큰따옴표를 포함해서 아래처럼 정확히 입력 후 저장:

         ".env"

       (따옴표 없이 저장하면 .env.txt로 저장되어 앱이 못 찾습니다. 꼭 따옴표
       포함해서 입력하세요.)


3. 실행하기
--------------------------------------------
LectureNotes.exe를 더블클릭하면 앱이 열립니다.

  - 창을 닫아도 시스템 트레이(작업표시줄 오른쪽 하단 숨김 아이콘 영역)에
    남아 계속 실행됩니다. 자동 녹음 기능을 쓰려면 이렇게 켜둔 채로 두세요.
  - 완전히 끄려면 트레이 아이콘을 오른쪽 클릭 → "종료"

  ※ NVIDIA 그래픽카드가 있는 컴퓨터라면, 처음 실행할 때 "GPU 가속 설정" 창이
    한 번 뜹니다. 약 1.3GB를 내려받으면 음성 인식이 훨씬 빨라집니다.
    - 지금 받지 않아도 괜찮습니다. 나중에 "설정 → GPU 가속 설정"에서 받을 수
      있고, 받지 않으면 CPU로 동작합니다 (느릴 뿐 결과는 나옵니다).
    - 한 번만 받으면 되고, 앱을 새 버전으로 바꿔도 다시 받지 않습니다.

    이건 이미 설치된 "그래픽 드라이버"와는 다른 파일입니다. 드라이버는 화면
    출력처럼 그래픽카드를 쓰기 위한 기본 프로그램이고, 여기서 받는 것은 그 위에서
    음성 인식 계산을 대신 처리하는 라이브러리입니다. 드라이버나 Windows 설정은
    전혀 바꾸지 않고 앱 전용 폴더에만 저장되며, 필요 없으면 삭제할 수 있습니다.


4. 기본 사용법
--------------------------------------------
  - "+ 새 강의 녹음"      : 마이크로 직접 녹음
  - "오디오 파일 불러오기" : 이미 녹음된 파일(mp3, m4a, wav 등)을 가져와서 처리
  - "자동 녹음 설정"       : 정해진 교시 시간표에 맞춰 자동으로 녹음 시작/종료
                            (앱이 켜져 있어야 동작 — 트레이로 내려가 있어도 OK)

  강의를 목록에서 클릭하면 오른쪽에서 요약 노트 / 전체 녹취록을 볼 수 있고,
  처리에 실패한 항목은 "다시 시도" 버튼으로 재시도할 수 있습니다.


5. 문제 해결
--------------------------------------------
  - 처음 녹음/파일 불러오기 시 시간이 오래 걸림
      → 음성 인식 모델(약 3GB)을 처음 한 번 인터넷에서 내려받기 때문입니다.
        이후에는 빠르게 처리됩니다.

  - "API 키가 없습니다" / "Could not resolve authentication method" 오류
      → 2번 과정을 다시 확인하세요. 파일 이름이 정확히 ".env"인지
        (뒤에 .txt가 안 붙었는지) 확인하세요.

  - NVIDIA 그래픽카드가 없는 PC에서 실행할 때
      → 자동으로 CPU 모드로 전환되어 동작합니다. 속도만 느려질 뿐 정상
        동작합니다.

  - 음성 인식이 너무 느림 (NVIDIA 그래픽카드가 있는데도)
      → "설정 → GPU 가속 설정"에서 GPU 가속이 설치되어 있는지 확인하세요.
        설치되어 있지 않으면 다운로드 후 앱을 다시 시작하면 빨라집니다.

  - GPU 가속 다운로드가 중간에 멈추거나 실패함
      → 인터넷 연결을 확인하고 다시 시도하면 됩니다. 중간에 받다 만 파일이
        남아 문제를 일으키지는 않습니다.

  - 인터넷 연결이 필요한 경우
      → 최초 음성 인식 모델 다운로드, GPU 가속 다운로드(선택),
        요약 생성(Claude API 호출) 시 필요합니다.
